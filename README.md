# Becoming — browser prototype update

This is an updated static-browser prototype based on the original Soft Landing project. Open `index.html` in a browser or publish it to a test GitHub Pages branch.

## Included in this update
- Becoming ocean-sunset styling and simplified Home/Reflect screens
- Two default daily spending/emotion questions, optional follow-ups, gratitude entries
- Mental Health sections and a short guided spending-urge flow
- Editable recovery journey dates, personal milestones and anniversary token previews
- Introductory spending recovery and spirituality resource cards with favorites
- Existing goals, wins, coping plans, breathing/grounding, local storage, export/restore
- Optional Simple View and reduced-motion CSS

## Important limitations
This is **not** a secure production app, iOS/Android native app, or finished feature-complete release. Do not use it for sensitive records. It does not implement secure storage, encryption, app lock, notifications, subscription billing, scholarships, cloud community, or actual token-image sharing. Anniversary tokens use approximate day thresholds; exact calendar-month/year calculations need implementation and testing. This update has not been published to the live GitHub site.

Existing browser data uses the original `sl_` storage keys for compatibility. Export a backup before changing a live site. Import supports original version 1 backups and updated version 2 backups. Test restore on a separate browser profile first.
